Customizing Colors & Theme Tokens

All colors, gradients, and blur intensities are centralized in assets/css/style.css using CSS variables.

:root { --primary: #4f46e5; /* Brand Primary */ --secondary: #06b6d4; /* Teal Accent */ --accent: #f43f5e; /* Rose Highlight */ --font-heading: 'Outfit', sans-serif; --font-body: 'Plus Jakarta Sans', sans-serif; }

Dark / Light Mode Toggle

LuminaStudio features an intelligent theme switcher with localStorage persistence. To make the dark theme default on initial load, change the root attribute in your HTML tag:

<html lang="en" data-bs-theme="dark">

RTL (Right-to-Left) Mode

For Arabic, Hebrew, and Persian languages, simply set dir="rtl" on the <html> element:

<html lang="ar" dir="rtl" data-bs-theme="light">
