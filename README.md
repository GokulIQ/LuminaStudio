## 🌟 Project Overview

**LuminaStudio** is a 100% pure-frontend, premium template crafted for photography businesses specializing in:

- 📸 **Studio Portraits** — Rembrandt lighting, editorial, corporate headshots
- 👔 **Executive & Fintech Headshots** — LinkedIn, board, Forbes profile photography
- 🛂 **Biometric Passport & Visa Photos** — Certified US, UK, Schengen, Canada, India specs
- 👶 **Infant & Newborn Photography** — Passport & milestone portraits
- 💒 **Wedding & Engagement** — Golden-hour, Tuscan villa, vineyard shoots
- 👗 **Fashion & Lookbook** — Haute couture, brand campaigns, editorial styling
- 🏢 **Corporate & Commercial** — Office, team, product, and marketing campaigns

The design language blends **Apple-style glassmorphism** with **Linear/Notion-grade UI clarity**, finished with subtle ambient gradient glows and micro-interactions for a "premium SaaS product" feel.

## 🎨 Customization Guide

### Brand Colors — 2-Minute Rebrand
Edit the CSS Variables in [assets/css/style.css](file:///c:/Users/gokul/Downloads/PhotoStudio/assets/css/style.css#L12-L90):

```css
:root {
  /* Primary Gradient */
  --primary: #6366f1;           /* Indigo base */
  --secondary: #ec4899;         /* Hot Pink accent */
  --accent: #06b6d4;            /* Cyan highlight */
  
  /* Full gradient used for buttons & badges */
  --gradient-primary: linear-gradient(135deg, #6366f1 0%, #a855f7 50%, #ec4899 100%);
  
  /* Fonts */
  --font-heading: 'Outfit', sans-serif;
  --font-body: 'Plus Jakarta Sans', sans-serif;
  
  /* Corner Radii (make it more "rounded" or more "sharp") */
  --radius-sm: 8px;
  --radius-md: 14px;
  --radius-lg: 20px;
  --radius-xl: 28px;
}
```

> 💡 **Pro Tip:** Swap the 3-color gradient for a 2-color one (e.g., Navy → Cyan for a fintech vibe) by replacing `--gradient-primary` with `linear-gradient(135deg, #0f172a 0%, #06b6d4 100%)`.

### Typography
Template ships with **Google Fonts** CDN:
- **Headings:** Outfit (weights 400–800) — geometric, modern, premium SaaS feel
- **Body:** Plus Jakarta Sans (weights 400–700) — excellent readability

Replace via the `<link>` in `<head>` of any HTML file.

### Logo & Brand Name
- Replace the **icon** inside `.brand-icon` (currently Font Awesome `fa-camera-retro`) with your SVG/PNG icon or the font-awesome class of your logo mark
- Change **"LuminaStudio"** text — brand text uses a gradient via `.accent` span

### Favicon
Replace `assets/img/favicon.svg` with your own SVG (or PNG) file.

## ⚙️ Technical Features & Conventions

### Theme System (Dark / Light)
- **Default:** Light Mode for first-time visitors *(not OS-preference based)*
- **Toggle Button:** `.theme-toggle-btn` with sun/moon icons
- **Persistence:** `localStorage` key `lumina_theme` (`'light'` | `'dark'`)
- **FOUC Prevention:** Every HTML page includes a **synchronous inline `<script>` in `<head>`** that reads `localStorage` and sets `data-bs-theme` *before* first paint. This eliminates the dreaded "dark mode flash."

```html
<head>
  <!-- This MUST be the FIRST script in <head> -->
  <script>
    (function() {
      try {
        var t = localStorage.getItem('lumina_theme') || 'light';
        document.documentElement.setAttribute('data-bs-theme', t);
      } catch(e) {}
    })();
  </script>
  ...
</head>
```

### RTL (Right-to-Left) System
- **Toggle Button:** `.rtl-toggle-btn` with `fa-right-left` icon
- **Persistence:** `localStorage` key `lumina_rtl` (`'true'` | `'false'`)
- **Stylesheet:** `assets/css/rtl.css` auto-injects when RTL is active
- **`<html dir>` Attribute:** Automatically toggled between `ltr` and `rtl`
- Perfect for Arabic, Hebrew, Persian, Urdu websites

### Responsive Breakpoint Strategy
Mobile-first architecture with 4 core breakpoints (standard Bootstrap 5):

| Breakpoint | Screen Size | Use Case |
|------------|-------------|----------|
| `xs` | ≤575px | Extra small phones (iPhone SE, small Android) |
| `sm` | 576–767px | Standard mobile phones |
| `md` | 768–991px | Tablets, iPad Mini, large phones landscape |
| `lg` | 992–1199px | Small laptops, iPad Pro landscape |
| `xl` | ≥1200px | Desktops & large laptops |

### Header Responsive Rules (Engineered for Zero Wrap)
- **Header always uses `flex-nowrap`** — single line, no wrap on any mobile size
- **Mobile buttons (≤768px):** Forced square `30–34px` with centered icons + `flex-shrink: 0`
- **RTL toggle text label hides on ≤768px** — icon-only, saves horizontal space
- **Brand logo `.accent` spans use `display: inline`** — preserves baseline alignment

## 🛠️ Engineering Conventions (Internal Standard)

Developers extending the template should follow these rules from `project_memory`:

1. **Utility-First Responsiveness** — Prefer Bootstrap utility classes (`d-lg-inline`, `flex-nowrap`) over custom inline `@media` styles
2. **Navbar Dropdown Visibility** — `.glass-card` navbars require `overflow: visible !important` to prevent dropdown menu clipping
3. **Asset Paths** — Always use `./assets/...` never `./assets./...` (typo causes 404)
4. **Brand Text Alignment** — Brand logo spans must use `display: inline`, never `inline-block` (breaks vertical baseline)
5. **No OS-Theme Default** — Default to `'light'` mode, never `matchMedia('prefers-color-scheme')` — explicit light default required
6. **FOUC Script Required** — Sync inline script in `<head>` of every HTML file to set `data-bs-theme` pre-paint

## 🔧 Troubleshooting FAQ

**Q: Mobile view has a slight horizontal scroll?**
→ Fixed in v1.0.0 via global `overflow-x: clip` on sections/rows/containers, `100vw→100%` on glow wrapper, and reduced stat-card negative offsets.

**Q: Theme flash on page load (FOUC)?**
→ Ensure every HTML page has the sync inline script in `<head>` *before* any CSS `<link>`.

**Q: Admin dropdown menu is clipped or not visible?**
→ Ensure the `.glass-card` navbar/container has `overflow: visible !important` (rule already in style.css).

**Q: Brand logo text alignment off on mobile?**
→ Check that `<span>` children inside `.brand-logo` use `display: inline` (not `inline-block`).

**Q: RTL not applying correctly?**
→ 1) Toggle the RTL button in header, 2) DevTools → `<html>` should have `dir="rtl"`, 3) `rtl.css` stylesheet must be loaded in `<head>`.
